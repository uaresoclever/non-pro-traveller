# Oh! A Non-Professional Traveller | 非專業旅人冒險

A bilingual travel website showcasing authentic hiking adventures, starting with Khao Yai National Park in Thailand.

## 🌟 Features

- 🌐 **Bilingual support** (English & Traditional Chinese)
- 📱 **Fully responsive design** for all devices
- 🔍 **SEO optimized** for global reach
- 🥾 **Detailed hiking trail information** with practical tips
- 📊 **Interactive trail comparison table**
- ❤️ **Authentic travel experiences** from a non-professional perspective

## 🚀 Live Demo

Visit: **https://nonprotraveller.netlify.app**

## 🛠 Built With

- **Content & Travel Experiences**: DC & Miyako's real adventures and insights
- **Code & Technical Implementation**: [Kiro AI](https://kiro.ai) assistance
- **Technologies**: HTML5, CSS3, Vanilla JavaScript
- **Deployment**: Netlify with GitHub integration
- **Collaboration**: Human-AI partnership

## 🏔 Current Adventures

### Khao Yai National Park, Thailand
Complete hiking guide featuring 7 major trails with:
- Difficulty levels and time estimates
- Parking and accessibility information
- Wildlife viewing opportunities
- Self-guided vs. guided trail requirements
- Driving convenience ratings

## 🔄 Local Development

1. Clone this repository
2. Open `index.html` in your browser
3. Or run a local server: `python3 -m http.server 8000`
